SoftAP Router WebUI

WebUI is not reachable / Web इंटरफेस नहीं खुल रहा है

🔄 Mobile IP may have changed / मोबाइल की IP बदल सकती है

🌐 Connect Mobile & PC / मोबाइल और PC को Connect करें

English: Mobile and PC must have a local network connection to each other.

हिन्दी: मोबाइल और PC के बीच local network connection होना जरूरी है।

1

📱 Mobile Hotspot

English: Turn ON Mobile Hotspot and connect the PC to the mobile's hotspot Wi‑Fi.

हिन्दी: मोबाइल Hotspot ON करें और PC को मोबाइल के Hotspot Wi‑Fi से connect करें।

2

📶 Same Wi‑Fi

English: Connect both Mobile and PC to the same Wi‑Fi router/network.

हिन्दी: मोबाइल और PC दोनों को एक ही Wi‑Fi router/network से connect करें।

3

🔌 USB

English: Connect Mobile to PC by USB. Enable USB Tethering if required by your setup.

हिन्दी: Mobile को USB से PC से connect करें। जरूरत हो तो USB Tethering ON करें।

4

▶️ Start Web Server

English: Open SoftAP Router and make sure its Web Server is running.

हिन्दी: SoftAP Router खोलें और सुनिश्चित करें कि Web Server चालू है।

🔗 Open Current WebUI / Current Address खोलें

English: Enter the current IP and port shown by the SoftAP Router app.

हिन्दी: SoftAP Router app में दिखाई गई वर्तमान IP और port डालें।

💡 Example / उदाहरण: http://192.168.88.x

🔄 IP Changed? / IP बदल गई?

English: Android can assign a new IP after hotspot restart, Wi‑Fi change, or reconnect.

हिन्दी: Hotspot restart, Wi‑Fi change या reconnect के बाद Android नई IP दे सकता है।

🛠️ Troubleshooting / समस्या समाधान

WebUI नहीं खुल रहा

Web Server ON करें और PC को उसी network पर connect करें। VPN/Proxy को अस्थायी रूप से बंद करके भी देखें।

पुराना IP काम नहीं कर रहा

App में current/new IP देखें। पुराने IP को permanent न मानें।

PC Hotspot से connected है फिर भी page नहीं खुलता

PC का VPN/Proxy बंद करें और Windows Firewall में WebUI port block न होने दें।

USB connection

केवल USB cable से network जरूरी नहीं बनता। आपके setup में आवश्यक हो तो USB Tethering ON करें।

⚠️ Important: 192.168.88.194 केवल example है। आपकी current IP अलग हो सकती है।

✅ Quick Checklist / त्वरित जाँच

☐ Mobile Hotspot/Wi‑Fi ON   ☐ PC सही network पर   ☐ Web Server ON

☐ Current IP सही   ☐ Correct port   ☐ VPN/Proxy blocking नहीं
